## Supplied model notes

```text
Card machine - complete 3D model (STL, millimetres)
Coordinate frame: origin from the base STL; Z up, base floor underside at Z = 0.
+Y = front (shuffler side), -Y = electronics casing. Machine centre plane X = 10.98.
00_complete_assembly.stl  every part in its assembled position (one file)
01..08                    each part separately, also in assembled position
04_gearbox_L_*  gearbox on the +X pad (as photographed); 05_gearbox_R_* its mirror image.
01 base and 02 casing are the supplied STLs, re-positioned; 03 shuffler casing is a simplified
envelope (bought-in part, sizes estimated from photos); 07/08 are simple blocks for clearance.
Gearbox parts are built from drawings GX-01 to GX-07 (module 0.6 involute gears).
```

Assembly and clearance-reference meshes are not a set of parts that should all be printed. The motor, breadboard and power-board meshes represent hardware envelopes. The shuffler casing is a simplified reference envelope.
