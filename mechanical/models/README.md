## Model notes

See [the supplied model notes](README.txt) for quantities, mirrored parts and dimensional assumptions. The assembly STLs include a motor envelope reference and shafts; they are assembly previews rather than a single print-in-place component. Shaft STL files represent 2 mm steel pins in the supplied notes. Reference dimensions inferred from photographs should be checked before fabrication.
